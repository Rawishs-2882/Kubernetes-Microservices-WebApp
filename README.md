# Kubernetes-Microservices-WebApp

Web application with independent login, product, and blog microservices, containerized and orchestrated with Kubernetes for scalability and service discovery.

## Features
- Independent login, product, and blog microservices
- Containerized with Docker
- Orchestrated with Kubernetes, including service discovery

## Tech Stack
Docker, Kubernetes, REST APIs

## Setup & Run
1. Build each microservice image: `docker build -t <service> ./<service>`.
2. Apply the manifests: `kubectl apply -f k8s/`.
3. Access services through the configured ingress/service endpoints.
